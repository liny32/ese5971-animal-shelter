# Data sources and snapshot

This directory contains the Austin Animal Center intake and outcome CSV snapshots used for ESE 5971 Milestone 2.

- `raw/intakes.csv` — 173,812 intake event records in the analyzed snapshot.
- `raw/outcomes.csv` — 173,775 outcome event records in the analyzed snapshot.

Public sources:
- [Austin Animal Center Intakes](https://data.austintexas.gov/d/wter-evkm)
- [Austin Animal Center Outcomes](https://data.austintexas.gov/d/9t4d-g238)

The public datasets can change after the snapshots were downloaded. Use the files in this repository to reproduce the reported numbers, and preserve them unchanged for this milestone. The data represent intake and outcome events, not verified daily on-site occupancy or shelter capacity. Please check the City of Austin's applicable dataset terms before redistributing these records elsewhere.
